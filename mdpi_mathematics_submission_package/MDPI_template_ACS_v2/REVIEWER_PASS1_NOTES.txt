[P1A] §3.3 — Missingness indicator convention REVERSED
  LOCATION: Line ~146
  TEXT: "m_⋅∈{0,1} is a derived indicator set to 1 if the
   corresponding anthropometric was originally observed (0 if missing
   before imputation)."
  ERROR: The convention is exactly BACKWARDS.
   Evidence 1: Variable names in confirmed code: "miss__height",
     "miss__weight", "miss__bmi" — "miss" = 1 means MISSING.
   Evidence 2: §5.4 (demo variant description): "height, weight, BMI
     values set to 0, their missingness indicators set to 1, and all
     anthropometric/missingness masks set to 0." In demo mode
     anthropometrics are ABSENT, yet missingness indicators = 1.
     If 1=observed this would be contradictory (saying "observed"
     when the field is intentionally removed).
   Evidence 3: CONFRONTATION PASS 1 confirmed: "demo mode: anthro
     values zeroed, miss flags set to 1" — miss flags = 1 when absent.
  CORRECT TEXT: "m_⋅∈{0,1} is a derived indicator (missingness flag)
   set to 1 if the corresponding anthropometric field is MISSING
   (0 if originally observed)."
  NOTE: The separate AVAILABILITY MASK uses the opposite convention
   (mask=1 if PRESENT), so the two conventions in the same system
   are: x_meta[5:8] = miss=1 if absent; mask[2:5] = 1 if present.
   This is a well-known dual representation in clinical ML. The text
   just had the x_meta miss indicator described backwards.
  SEVERITY: HIGH — Reviewers reading both §3.3 and §5.4 will catch
   this contradiction immediately.

[P1E] §4.4 + §4.5 + §7.5 — q_meta is effectively 1 for all
       PTB-XL records with demographics present; attribution of
       graceful degradation needs clarification
  LOCATIONS: Lines ~194 (§4.4), ~213 (§4.5), ~416 (§7.5 Q3)
  ISSUE:
   q_meta = min(1, q_d + 0.5*q_a)
   In PTB-XL: age available 98.7%, sex always → q_d = 1 for 98.7%
   When q_d = 1: q_meta = min(1, 1 + 0.5*q_a) = 1 regardless of q_a.
   Therefore q_meta = 1 for virtually all demo and demo+anthro records,
   regardless of whether height/weight/BMI are present or absent.
  CONSEQUENCE: The claim in §4.5 "aggressively suppressing metadata-
   to-ECG cross-talk at partial availability" refers to DEMOGRAPHIC
   partial availability (age missing, ~1.3% of PTB-XL), NOT to
   anthropometric partial availability (height/weight missing, ~69%).
   The graceful degradation shown in Fig. 5 (missingness stress test)
   is driven by:
    - Explicit missingness flags (m_h, m_w, m_bmi) in x_meta
    - Sample meta-dropout during training
   NOT by q_meta scaling (which is constant = 1 throughout the
   anthropometric masking experiment since demographics are present).
  The §7.5 Q3 text says "joint mechanism of q_meta scaling...zero-
   initialised residual injection...and sample meta-dropout" which is
   technically fine (joint mechanism), but attributing robustness to
   q_meta is misleading for readers who will compute q_meta values.
  §4.4 already correctly notes q_d=1 for 98.7% of records — the
   issue is subsequent text implying q_meta varies with anthropometric
   availability.
  FIX RECOMMENDATION: Add one clarifying sentence in §4.4 or §4.5:
   "In practice for PTB-XL, q_meta equals 1 for all records where
   demographics are present (98.7% of records); attenuation below 1
   occurs only when age is unavailable. Anthropometric missingness
   robustness is therefore driven primarily by the explicit missingness
   flags (m_h, m_w, m_bmi) in x_meta and by sample meta-dropout,
   rather than by q_meta scaling."
  SEVERITY: MODERATE — A reviewer who computes q_meta for PTB-XL
   will catch this. Failing to clarify could lead to a request for
   major revision.
