  but has no public pre-registration (OSF, AsPredicted). A very strict
  reviewer might ask for this. However: (i) supplementary Table S1
  documents the family; (ii) "pre-specified" means specified before
  analysis, not necessarily publicly registered; (iii) this is standard
  practice for this type of measurement paper. Answerable in rebuttal.

  ("No statistical test across the 20 runs as if independent"). A reviewer
  could ask for clarification; answerable in rebuttal.

  below its reference weight of 0.10×q_meta. Correct as stated. ✓
