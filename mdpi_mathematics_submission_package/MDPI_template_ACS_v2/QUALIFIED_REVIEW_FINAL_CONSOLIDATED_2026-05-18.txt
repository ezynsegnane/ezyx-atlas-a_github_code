FINAL QUALIFIED REVIEW - CONSOLIDATED REMARKS
Date: 2026-05-18
Manuscript: main_en.tex / main_en.pdf
Reviewer stance: professional external reviewer, ML/statistics/reproducibility

Executive verdict
-----------------
The manuscript's scientific core is defensible: the 20-seed Group A raw JSON
files support the reported macro-AUC means and paired differences. The paper's
best contribution is a careful measurement of a very small metadata effect,
not a large performance jump.

The submission is not yet immune to reviewer attack. The highest-risk problems
are version-control and reproducibility mismatches between the manuscript,
local supplementary snapshot, and public derived artifacts.

Critical issues to fix before submission
----------------------------------------

[C1] Public derived artifacts still describe a 10-seed/30-run version.
Location: Data Availability line 517; public results files.
Evidence:
- Public raw Group A JSON files: 60 files, consistent with 20 seeds x 3.
- Public seed_level_results.csv: 30 rows only, 10 per variant.
- Public statistical_analysis_full.json: seeds 2024-2033 only.
- Public table_results_latex.tex: "10 graines aleatoires".
- Public statistical_analysis_protocol.md: 10 seeds and 36-test family.
- Public CITATION.cff: "All 30 runs (10 seeds x 3 variants)".
Fix: regenerate all derived artifacts from the 60 Group A JSON files and update
CITATION.cff/protocol/report/table.

[C2] Missingness robustness is not publicly reproducible as written.
Location: abstract line 75; results line 355; Fig. 4 line 708.
Manuscript says: 20 seeds, all three variants, anthropometric fields only.
Public script/report show: 10 seeds, demo+anthro-only summary, and code that
zeros all metadata features/masks at missingness rather than only height,
weight, and BMI.
Fix: publish the exact 20-seed anthropometric-only missingness script/report
used for Fig. 4, or revise the manuscript to match the public experiment.

[C3] Local source_snapshot contradicts the manuscript architecture.
Location: source_snapshot/eznx_model_v5.py; manuscript lines 180, 226, 243.
The local snapshot lacks the public W_addon/arch_mode implementation. If this
snapshot is bundled, reviewers can claim the source does not match the 3.95M
parameter budget and Group E architecture description.
Fix: replace source_snapshot with the exact current source or remove it from
the submission package and rely on a tagged GitHub release.

[C4] "Pre-declared 3-test family" needs a consistent protocol artifact.
Location: abstract line 75; protocol lines 320-329; supplementary line 507.
The manuscript says the confirmatory family is 3 macro-AUC contrasts. The
public protocol says 36 tests and 10 seeds. Local package has no visible Table
S1/protocol file.
Fix: include a correct Table S1/protocol and remove stale public protocol.

[C5] Data Availability is broader than the current artifacts support.
Location: line 517.
"Complete code, all seed-level result JSON files, derived statistical artifacts"
is attackable while derived artifacts are stale and patient-level predictions
are absent.
Fix: narrow the claim or synchronize every artifact.

Major interpretive issues
-------------------------

[M1] Fold-10 claim is too broad.
Group F tests only demo+anthro on alternative folds. Say fold 10 gives lower
absolute full-metadata performance, not that all metadata gains generalize or
are conservative across splits.

[M2] Missingness mechanism should not be sold as mainly "quality-gated".
q_meta saturates to 1 when age/sex are present. The likely robustness drivers
are missingness indicators and sample meta-dropout. Keep this wording in the
abstract, Table 9, Fig. 4 caption, and conclusion.

[M3] Exploratory groups need softer language.
Replace "confirm", "demonstrates", and bare "significant" for Groups B-E with
"exploratory", "descriptive", "associated with", or "did not show detectable
sensitivity". Group D exact p from public JSON is 0.002325, but it is still
exploratory/uncorrected.

[M4] Practical significance needs one more explicit sentence.
The full-metadata gain is about +0.0019 macro-AUC. State clearly that no
clinical decision benefit, calibration benefit, or net-benefit improvement is
claimed.

[M5] Missingness masking design needs clarification.
Independent masking of height, weight, and BMI may create unnatural states
because BMI is derived from height/weight. Either justify as stress testing or
add a joint anthropometric-field masking sensitivity.

[M6] HYP interpretation should be softened.
"Not merely a power limitation" is strong. Prefer: the data make a large HYP
effect unlikely under this protocol, but smaller/subclass effects remain open.
