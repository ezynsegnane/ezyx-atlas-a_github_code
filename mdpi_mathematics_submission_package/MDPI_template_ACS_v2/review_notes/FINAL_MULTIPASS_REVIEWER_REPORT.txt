================================================================================
EXECUTIVE SUMMARY
================================================================================

Le manuscrit EZNX-ATLAS-A presente une etude de mesure rigoureuse et
pre-declaree de la contribution incrementale des metadonnees cliniques a la
classification ECG sur PTB-XL. Son design (20 seeds, Wilcoxon apparie, BH-FDR
sur famille de 3 tests pre-specifiee) est methodologiquement solide. La
transparence sur les limitations est exemplaire (9 limitations detaillees).
Tous les 39 citations sont presentes dans la bibliographie. Les chiffres
bootstrap CIs, p-values et les moyennes/SDs macro-AUC sont verifies corrects.

CEPENDANT, une inspection hostile revele:
(1) 3 problemes CRITIQUES qui bloquent la publication sans correction.
(2) 10 problemes MAJEURES qui seraient signales par un reviewer competent.
(3) 12 problemes MODEREES attaquables par un reviewer attentif.
(4) 8 problemes MINEURES ameliorant la qualite globale.
Les points (1)-(2) doivent etre traites avant soumission. Les points (3)-(4)
sont fortement recommandes. Le manuscrit est publiable apres corrections.

MP001 -- [Sec 3.3 / ligne 166] -- CRITIQUE (P02)
Section: Metadata extraction and normalisation
Observation: Le manuscrit affirme "their mask bits are always 1" pour les
  missingness indicators (m_h, m_w, m_bmi). Or, le code index_construction.py
  (lignes 158-160) montre que mask__miss_height = mask__height, qui vaut 0
  quand height est absent. Pour PTB-XL avec 68% de height manquants, ce masque
  est 0 dans la majorite des cas. La description "always 1" est factuellement
  incorrecte et peut induire un reproducteur en erreur.
  De plus, cela implique que les missingness indicators dans x_meta ont leurs
  masques de disponibilite a 0 precisement quand ils valent 1 (quand la valeur
  manque) -- un comportement contre-intuitif non discute dans le manuscrit.
Risque reviewer: "Votre description est contredite par votre propre code."
Action: Corriger Section 3.3: remplacer "their mask bits are always 1" par "their
  mask bits mirror the availability of the corresponding anthropometric value
  (mask__miss_height = mask__height, etc.)." Ajouter dans Section 4.3/7.4 une
  explication que la robustesse sous masquage est principalement due au
  meta-dropout et aux valeurs imputees (median), pas aux missingness indicators
  (qui sont eux-memes masques quand les valeurs manquent).
Statut: NEW (non dans R001-R044 originaux s'ils existent)

MP004 -- [Sec 5.1 / Loss weights / ligne 260] -- MAJEURE (P01, P02)
Section: Composite multi-task loss
Observation: Pour Group C (lambda_LAUC varies de 0.00 a 0.16), le code normalise
  tous les poids par total_w = fused_w_raw + ecg_w + meta_w + lauc_w. Pour
  lambda_LAUC != 0.08, total_w != 1.0 et la normalisation modifie ecg_w et

  principal pour Group C. La Section 5.4 ligne 293 note seulement que
  "w_fused = max(0, 0.60 - lambda_LAUC), so both weights change simultaneously"
  sans mentionner la normalisation par total_w.
Risque reviewer: "Pour Group C, les poids reels sont normalises -- tous les poids
  changent, pas seulement lambda_LAUC et w_fused."
Action: Dans la description de Group C (Sec 5.4 ligne 293), ajouter une note:
  "Note that the code additionally normalises all weights by total_w (their sum)
  to ensure a bounded effective loss; for the values tested (lambda_LAUC in
  {0.00, 0.04, 0.08, 0.12, 0.16}), total_w ranges from 1.00 to 0.98, making the
  renormalisation effect marginal but not zero."
